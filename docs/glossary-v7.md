# 术语表（JA → ZH / EN / VI / PT）v7

## 使用规则

1. 翻译时必须使用本表译法，不得偏离。
2. 标准列以驾校教材通行译法为基准；教材内一词多译的，按出现频次选定**唯一**写法。
3. 表中没有的术语，翻译后列入「New terms to add」。
4. 括号规则：译法中括号内的部分只在**该术语在一道题内首次出现**时带上，之后省略。例：首次「停车（短时）」，之后「停车」。
5. 易混词固定对应，任何情况下不得互换：
   - 停车（停車）≠ 驻车（駐車）≠ 暂停（一時停止）≠ 停留（停止禁止部分）
   - 超车（追越し，变道）≠ 超过（追抜き，不变道）；**「超越」禁用**（教材中两义混用）
   - 打信号（合図）≠ 信号灯（信号機）≠ 手势信号（手信号）；正文不得单用「信号」二字指信号灯
   - 标识（標識，立牌）≠ 标示（標示，画在路面）；一字之差，首次出现时加注「路面」或「立牌」
6. ZH 专用规则：日文「青」一律译「绿」；「标示」不得译成「标线」；「限制标识」即規制標識（含禁止与指定）；解说中「缓行」首次出现时注「缓行（徐行）」。
7. EN / VI / PT 译法来源，按优先级：
   1. **官方译法优先**：警察庁・都道府県警察、警視庁、県警监修的多语言交通资料（见文末「官方来源」）。v7 已逐条核对，与官方一致或已改从官方的条目见「v7 官方核对结果」。
   2. 官方资料未覆盖时，取驾校多语言练习题的通行用词（仅取词汇，不取句子）；题内一词多译的按频次选定唯一写法。
   3. 两者都没有、或练习题译法有误时，用该语言的规范交通用语（VI 参照越南道路交通法，PT 参照巴西 CTB）。
   - 与官方译法不一致的少数条目，均在「v7 官方核对结果」中写明理由；**不得在未记录理由的情况下偏离官方译法**。
   - 官方资料本身互相冲突时（如 踏切 的 railway / railroad / level crossing），选定一个并在该节记录被弃用的写法。
8. 日本特有概念首次出现时带日文括注：徐行、一時停止、路側帯、路肩、仮免、原付、クリープ、ミニカー。

| 一般原動機付自転車 | VI | xe gắn máy (原付) | xe đạp gắn động cơ（NPA） | 官方是 原動機付自転車 的逐字直译，越南读者不这么说。`xe gắn máy` 是越南道路交通法对 50cc 以下的法定车种名，与 `xe mô tô`（>50cc，对应自動二輪車）正好成对，学习者一读就懂 |
| 停車 / 一時停止 | VI | dừng xe / tạm dừng | NPA 在驻停车禁止处把 停車 也写成 tạm dừng xe | 官方在这一处让两词重合，而本表规则5要求 停車 ≠ 一時停止 永不互换。越南法本身区分 dừng xe（短时）/ đỗ xe（驻车），按越南法保留三分 |
| 運転者 | VI | người lái xe | người điều khiển phương tiện（NPA） | 官方用语正确但过长，题干里每题都出现会明显拖长行宽（design G3：越南语本就比日文长30–40%）。`người lái xe` 语义等同 |
| 一方通行 | VI | Đường một chiều | đường lưu thông một chiều（NPA） | 同上，取短形；语义无差 |
| 標識 / 標示 | PT | sinalização vertical / horizontal | placas / sinalizações viárias（NPA） | 官方用的是日常说法，不成对；巴西 CTB 的 vertical／horizontal 才是成对的法定术语，正好承载本表「标识／标示」的固定区分（规则5第4条）。`placa` 仍可在解说中作日常同义词 |
| チャイルドシート | PT | cadeirinha infantil | assento de segurança para crianças（GIFU）、cadeira para criança（GUNMA） | 两份官方写法互不一致且都偏长；`cadeirinha` 是巴西通行说法。CTB 正式名 dispositivo de retenção para crianças 更长，不适合题干 |

## v5 取舍说明（EN / VI / PT）

**EN**（来源：Learner's Permit Test 150 题 + English Exercises 250 题）
- 徐行＝slow down（60 次）；原付：题内 moped（38）与 general motorized bicycle（23）混用 → 定为 general motorized bicycle (moped)，以便与 specified small motorized bicycle 区分。
- 追越し＝overtaking（77），追抜き＝passing；題内 pass/passing 两义混用，正文中 passing 只用于追抜き。
- 题内 yield / give way 混用 → give way；railroad / railway crossing 混用 → railway crossing（8:2）。
- 一時停止：题内无固定译法（temporary stop 仅 1 次且语法有误）→ stop (一時停止)。

**VI**（来源：ベトナム語 150 题，OCR 噪声大，且原译文质量不稳定）
- 未采用的练习题译法：原付＝xe máy điện（意为电动摩托，错误）→ xe gắn máy（越南法律用语，正好指 50cc 以下）；標識/標示 均作 kí hiệu → biển báo / vạch kẻ đường；踏切＝đường ray（意为铁轨）→ đường ngang đường sắt；路面電車＝tàu bus điện → tàu điện mặt đất；合図＝tín hiệu（与信号灯混）→ báo hiệu。
- 采用的：đi chậm（徐行，21 次）、tạm dừng、chuyển làn、giao lộ、người đi bộ、xe thô sơ（軽車両，亦为越南法律用语）、nhường đường、đường ưu tiên、khu vực an toàn。
- 停車/駐車＝dừng xe / đỗ xe（越南法律本身有此区分，可直接对应）。

**PT**（来源：ポルトガル語 150 题，巴西葡语，质量较好）
- 采用：sinalização vertical / horizontal（標識/標示）、faixa de pedestres、passagem de nível、via preferencial、conversão em duas etapas / giro curto、condutor（24，弃 motorista）、distância de reação / frenagem / parada、condutor novato、bonde。
- 原付：题内 bicicleta motorizada（15）、ciclomotor（6）、motoneta（1）混用 → bicicleta motorizada comum；特定小型 → bicicleta motorizada pequena específica。
- 一時停止：题内 parada momentânea 与 parada obrigatória 混用 → parada momentânea（parada obrigatória 易与停止线、停车混淆）。
- 安全地帯：zona de segurança（2）优先于 área segura（1）。
